# 東京・関東 デート候補カタログ

東京・関東圏のデート先候補(351件・15ジャンル)を一覧できる静的ページです。

- 公開ページ: https://sakimyto.github.io/tokyo-date-spots/
- `index.html` … 一覧ページ(1ファイル完結。ジャンルタブ・検索・エリア絞り込み・お気に入り・「今やっている」・ランダム)
- `spots.json` / `spots.csv` … 同じデータ(名前、エリア、説明、公式URL、会期など)
- `build.py` … `spots.json` から `index.html` を生成するスクリプト(テンプレート `tpl.html` は作業用ディレクトリ側で管理)

会期・営業状況は変わることがあります。出かける前に各公式サイトで確認してください。
