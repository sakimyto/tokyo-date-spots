# 東京・関東 デート候補カタログ

東京・関東圏のデート先候補(376件・16ジャンル)を一覧できる静的ページです。期間限定のキャラクター・コラボイベントも載っています。

- 公開ページ: https://sakimyto.github.io/tokyo-date-spots/
- `index.html` … 一覧ページ(1ファイル完結。ジャンルタブ・検索・エリア絞り込み・お気に入り・「今やっている」「これから」・ランダム。会期が終わったものは自動で非表示)
- `spots.json` / `spots.csv` … 同じデータ(名前、エリア、説明、公式URL、会期、会場、予約・整理券など)
- `tpl.html` … ページのテンプレート
- `build.py` … `spots.json` と `tpl.html` から `index.html` を生成(`python3 build.py 2026-10-20` のように最終更新日を渡す)

会期・営業状況は変わることがあります。出かける前に各公式サイトで確認してください。
